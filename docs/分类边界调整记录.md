# 分类边界调整记录

日期：2026-09-15。已在本地完成；本记录不表示远程发布。

## 分类定义

- **年代怀旧**（稳定 ID `retro`）：以近现代日常生活、大众文化和旧媒介的时代记忆为主体。编辑主题必须交代回望的地域、生活对象以及当代如何重新组合这些参照，不只靠泛化的旧物氛围建档。
- **历史装饰**（稳定 ID `classical-decorative`）：以历史样式、装饰运动和地域工艺传统为主体，研究形式、材料、制作和传播。不等于古典主义，也不要求所有条目繁复华丽。
- 主分类按研究对象决定，不以1900年等日期一刀切；“复古感”可以跨类别，历史样式不重复建档。编辑分类不宣称是统一的学术谱系。

## 新版UI衔接

当前首页为 `CabinetHome.vue`，分类入口和说明来自 `components/cabinet/collections.ts`，名称来自 `content/categories.ts`，数量由内容库计算。此次只调整共享名称和两个分类的说明；沿用新版首页、目录、详情、导航和动画结构。

全部120个档案ID、分类ID、原图路径和收藏标识保持稳定。旧档案名称加入搜索别名；旧分类URL继续有效。更名海报的标题与必要边栏文案由现有固定SVG排版重新渲染，保留场景和四色数值，浏览图片同步更新。Art Deco和奥斯曼档案使用“装饰艺术”“奥斯曼纹饰”作为短海报标题。

分类清单按当前归属重排编号。旧批次建设记录保留当时统计；`retro`配方目录表示初始制作批次，不再表示当前分类。第三批核验按实验家居迁移后的分布检查，并随分类数量调整拼图宽度。
