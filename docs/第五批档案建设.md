## 内容与制作边界

每份档案独立提供四个编辑设定的主题色、设计笔记、应用建议、相关推荐，以及至少三个逐阶段引用的历史节点和至少两项可追溯资料。历史运动、编辑主题和网络审美分别说明范围，不将当代名称写成统一成立的历史流派。

资料以博物馆、图书馆、大学、设计机构和创作者的一手记录为主。部分机构页面直接访问返回 403，相关事实依据搜索返回的机构正文核对；这不等于全部来源链接均能在任意网络直接打开。上海博物馆馆刊已下载并检查 PDF 第 39—42 页，月份牌文章的篇名、1914 年实例与技法说明已核实。

内置 imagegen 为每份档案生成独立场景，完整提示词与参数保存在 `templates/posters/batch-five`，场景保存至 `assets/poster-scenes`。使用既有 `scripts/render-posters.ts` 输出 `public/images/originals` 中的 1200 × 1500 海报，文字与色卡采用确定性排版。

## 复现与核验

```powershell
npm run poster:render -- templates/posters/batch-five
npm run check
node scripts/verify-fifth-batch.mjs
```

验证脚本逐项对照本批40个稳定ID，检查分类、场景与原图唯一性、资源尺寸、160个色卡中心像素、80张浏览图片，并核对全库120份档案与清单逐条对应且没有待收录条目。逐类联系表位于 `artifacts/batch-five`。
