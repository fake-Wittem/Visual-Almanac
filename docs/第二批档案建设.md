# 第二批风格档案建设

完成日期：2026-09-10。

## 建设结果

本批新增 **12 份档案、12 张海报、36 个设计史阶段、48 个色卡**。古典装饰、先锋实验、街头流行各新增 4 份；档案馆累计 **40 份、8 个分类**。扩充清单共 120 个候选，已收录 40、待收录 80。

每份档案包括概述、独立设计笔记、应用建议、相关风格，以及至少三个按时间排序并关联来源的发展阶段。正文区分历史流派、艺术运动和社群文化，未增加实际项目验证或实践记录。

## 视觉与内容边界

- 古典装饰：巴洛克用阶梯厅表现空间戏剧性；洛可可用器物表现细密装饰；工艺美术用印版与连续织物纹样表现制作；新艺术用彩窗与金属植物线条表现结构和装饰的联系。
- 先锋实验：孟菲斯是家具与表面组合；达达是图像与文字错置；超现实主义采用原创梦境关系；欧普艺术呈现静态线条产生的知觉变化。
- 街头流行：波普关注大众商品与印刷；涂鸦字形限定纽约书写文化线索；朋克 DIY 关注自主出版；滑板文化关注器材、运动与社群传播。
- 洛可可与已有法式沙龙、工艺美术与自然手作、孟菲斯与包豪斯、达达与朋克分别明确范围，并以相关档案连接。
- 海报为原创生成演绎，不是历史图像、馆藏复制或真实场地记录；配色标记为 `manual`。

## 来源维护

本批研究资料来自 V&A、The Met、MoMA、Design Museum、纽约市博物馆、Morgan Library、MOCA、史密森尼及大学机构。各项具体链接、出版机构与阶段引用保存在档案的 `designHistory.sources` 和 `timeline[].sourceIds`，直接展示在详情页 REFERENCE。

例如：[V&A 巴洛克概述](https://www.vam.ac.uk/articles/the-baroque-style)、[MoMA《反应的眼睛》](https://www.moma.org/interactives/moma_through_time/1960/the-responsive-eye/)、[MoMA 自出版刊物](https://www.moma.org/explore/inside_out/2011/05/18/looking-at-zines/)分别支撑空间整体设计、知觉艺术与自出版传播的历史线索。采集日期为 2026-09-10；网络来源可能后续调整，结构校验本身不证明史实。

## 可复用生产结构

- 场景源图：`assets/poster-scenes/<styleId>.png`。
- 本批配方和最终场景提示词：`templates/posters/batch-two/*.json`。
- 最终海报：`public/images/originals/<styleId>-poster.png`。
- 共用排版器：`scripts/render-posters.ts`，沿用第一批的纸张外框、单幅中央画面、四列色卡和三枚标签。
- 可选 `titleColors` 控制两个标题片段的墨色，用于浅色主题；不影响主题色卡。洛可可使用深棕与灰玫瑰墨色提高对比。
- 共用 `DesignHistory.vue` 与内容 schema 自动承接新增档案，无需增加详情页组件。
- 分类字典新增三类，标签字典补充“拼贴、字形、网点”。

本批使用内置 imagegen，每个风格独立调用。配方保存专属提示词，调用时统一补充：生成 1536 × 1024 横向中央场景，外围标题、边框、色卡与标签由现有排版器处理，不生成水印。生成源图保留在仓库，普通网站构建不依赖图像生成服务。

```bash
npm run poster:render -- templates/posters/batch-two
npm run check
```
