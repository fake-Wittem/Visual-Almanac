# 动效体系

动效用于解释状态变化：页面淡出后进入，筛选卡片保留位置关系，弹层退出后再释放焦点和滚动。基于 Vue 内置 Transition / TransitionGroup、ResizeObserver 和浏览器动画能力实现，无新增依赖。

## 统一参数

`src/styles/motion.css` 是动效参数与样式入口，由 `src/main.ts` 加载。

| 参数                       | 默认值                         | 用途                     |
| -------------------------- | ------------------------------ | ------------------------ |
| `--motion-fast`            | 150ms                          | 控件反馈、短暂退出       |
| `--motion-duration`        | 220ms                          | 淡入淡出、弹层           |
| `--motion-layout-duration` | 280ms                          | 高度变化、列表重排、缩放 |
| `--motion-page-duration`   | 300ms                          | 页面和图片进入           |
| `--motion-ease`            | cubic-bezier(0.22, 1, 0.36, 1) | 布局与进入缓动           |
| `--motion-distance`        | 8px                            | 轻微位移                 |

不要在业务组件添加独立动画时长，也不要使用 `transition: all`。数值插值使用 ease-out 三次曲线，时长沿用布局参数。

## 可复用组件

### MotionTransition：单元素显隐或替换

支持 `fade`、`page`、`popup`、`modal` 四种 preset，默认 fade；支持 `mode`、`appear` 和 Vue 过渡生命周期事件。插槽需要一个元素或单根组件；内容替换需要稳定的 key。

```vue
<MotionTransition preset="popup">
  <div v-if="open" class="panel">弹层内容</div>
</MotionTransition>

<MotionTransition mode="out-in">
  <div :key="selectedId">当前内容</div>
</MotionTransition>
```

退出元素自动设置 inert，防止退出途中仍被点击或获得焦点；取消退出时恢复。只为实际内容变化设置 key，不要把整个筛选页按 query 重新挂载，以免丢失输入焦点。

### MotionList：增删和排序

```vue
<MotionList class="style-grid">
  <StyleCard v-for="item in items" :key="item.id" :style="item" />
</MotionList>
```

支持 `tag` 和 `appear`；直接子节点必须有唯一、稳定的业务 key。组件冻结退出节点的宽高与位置，Vue 使用 FLIP 平移保留项；结束或取消后清除临时样式。禁止使用数组索引作为可重排列表的 key。

### MotionLayout：内容高度变化

```vue
<MotionLayout>
  <MotionList class="tag-options">...</MotionList>
</MotionLayout>
```

观察内部内容高度，平滑调整外层高度；适用于筛选标签展开、结果数量变化、配色内容切换。连续变化从当前显示高度重新开始，不堆积动画。完成后恢复自然布局，卸载时取消动画并断开观察器。默认不裁切内容，以保留色块提示和焦点轮廓；不要放在需要让插槽根节点直接参与父级 flex/grid 的位置。

### useMotionNumber：连续数值过渡

```ts
const zoom = ref(1)
const displayZoom = useMotionNumber(zoom)
```

业务值即时更新，展示值逐帧趋近目标；再次操作从当前值继续。图片查看器以展示倍率计算滚动中心，避免缩放跳跃。卸载和系统偏好变更时取消帧任务。

## 接入范围

- 页面：首页、收藏、详情、404；按路径切换，query 更新留在当前页面。
- 筛选：卡片增删和重排、活动条件、展开标签、高度、结果数量、空状态、分页和尾部说明。
- 弹层：排序菜单、移动端筛选、图片查看器、Toast、返回顶部按钮、色块提示。
- 详情：图片加载与切换、配色方案切换、观察底色、缩放、收藏按钮反馈。

`ModalDialog` 通过 `v-model:open` 控制。不要在它外层使用 `v-if` 强制卸载，否则退出动画无法完成。图片查看器采用同样约定。关闭动画完成后才恢复页面滚动和原焦点；路由卸载时也会清理。

页面使用 out-in；`src/app/pageMotion.ts` 在旧页面退出与新页面挂载间协调滚动恢复，不使用固定延时。列表页离场时冻结自身查询，详情通过路由 props 接收 id，防止旧页面响应新路由而闪出错误内容。

## 可访问性与验证

系统开启 `prefers-reduced-motion: reduce` 后禁用 CSS 动画和过渡，数值与高度立即更新，业务行为不变。设置动态变化也会取消正在进行的 JavaScript 动画。

修改时应检查：连续筛选/排序、空状态恢复、快速开关弹层、Esc 关闭与焦点恢复、取消收藏与撤销、详情返回列表的滚动恢复、移动端溢出、减少动态效果模式。视觉验收要在浏览器中检查实际样式和中间帧；类型检查和生产构建不能替代它。
