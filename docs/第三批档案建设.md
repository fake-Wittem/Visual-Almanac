## 内容边界与素材

每份档案包含摘要、四个手工设定的主题色、设计笔记、应用建议、相关档案，以及至少三个有引用的发展阶段和至少两项来源。历史运动、地域传统、媒介专题与当代编辑主题分别表述，不将后者虚构为统一成立的流派。

本批重点区分乌尔姆教学方法与德国企业产品、宋代不同窑口与用途、哥特式建筑与哥特复兴及哥特亚文化、历史未来主义与当代未来科技。历史材料与当代视觉提炼分别放在设计史和图像说明中。

场景由内置 imagegen 生成，复用前次已成功生成的素材并补齐缺图；不是历史照片、馆藏复制或实际项目记录。场景保存在 `assets/poster-scenes`，完整提示词与固定排版参数保存在 `templates/posters/batch-three`，原图位于 `public/images/originals`。标题、四列色卡、HEX、标签与页脚均由既有 `scripts/render-posters.ts` 排版，32张新海报统一为1200×1500。没有引入新的图像服务依赖。

## 复现与检查

```powershell
npm run poster:render -- templates/posters/batch-three
npm run check
node scripts/verify-third-batch.mjs
```

`verify-third-batch.mjs` 检查八类各4份、32张不同原图、128个色卡中心像素、配方与档案色名/HEX、资源登记尺寸和64张浏览图片，并输出每类四图联系表到 `artifacts/batch-three`。来源正文经过制作时逐项查阅；结构校验检查逐阶段引用关系，不代替对设计史内容的判断。

验收结果：88 项测试通过；72 份档案与72张原图的内容校验、类型检查和生产构建通过，生成144张浏览图片。第三批32张海报已逐类目视检查，128个色块全部精确匹配，标题浅色对比问题已修正。原有12张复古重制批次检查仍通过。

Playwright 在本地生产预览中检查全部8类计数与32个新增详情页，图片、至少3个历史阶段和至少2项参考资料均正常呈现，未发现页面脚本错误。390px手机视口抽检德国理性产品、朝鲜白瓷、解构建筑、Rave四份详情及东方意境分类页，未发现横向溢出；桌面与手机列表/详情截图保存在 `output/playwright`。本次未执行远程部署。
