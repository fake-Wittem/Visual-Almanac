# UI 重构后的代码整理

## 范围

保留已确认的档案馆 UI、页面路径、内容数据、收藏记录和配色行为。本次为代码引用审查、清理与结构整理，没有启动预览，没有执行测试、类型检查或构建。之前的 QA 截图与 passed 记录仅代表当时版本。

## 删除

- 无运行引用的 `src/components/catalog/StyleCard.vue`；详情推荐栏已经使用 `ArchiveRecord`。
- `main.css` 中 52 条旧导航、旧页脚、旧卡片等无引用规则。
- 未被现行页面使用的展示衍生素材：`baroque.webp`、`bauhaus.webp`、`british-academia.webp`、`chinese-literati.webp`、`folder-narrow.webp`（均位于 `public/images/cabinet/`）。
- 已弃用窄档案袋的源图 `assets/cabinet-originals/folder-narrow.png`。
- 上述七个实体文件共 2,668,015 字节。现行素材源图、内容海报原图与选定设计参考均保留。

## 结构与交互整理

- 独立 `RecordPalette` 管理配色浮层；仅展开时注册外部点击监听，关闭或卸载时解除。
- 浮层使用 Vue 实例唯一 ID，避免同一档案重复呈现时的 DOM ID 冲突；Esc 关闭后回到触发按钮，Tab 离开时关闭。
- 样式拆分为共享主题、首页、档案卡片、回顶按钮四个文件；拆分时保留各模块内部的媒体查询与覆盖顺序，并清除九处同作用域的重复属性及失效背景规则。
- 回顶按钮去除旧版矩形样式及无效移动端覆盖，保留黄铜风格；消除与通用 popup 位移动效叠加。
- 首页/列表页面按路由异步加载；没有声称实际包体积改善，需后续构建测量。
- 首页分类计数一次汇总，模板不再反复筛选完整档案列表。
- 退出动画在断点变化、减少动态效果偏好变化和组件卸载时清理；修正原主档案退场时的层级。
- 筛选、排序、清空等操作取消尚未执行的搜索防抖，避免旧搜索回写条件。
- 减少动态效果偏好下关闭全局平滑滚动；回顶状态在浏览器页面恢复时同步。

## 保留项

`ColorTooltip`、`ArchiveImage` 仍用于配色详情、参考图和图片查看器，不属于废弃组件。历史设计文档作为设计过程记录保留。现行生成素材源图仍用于后续修改，因此未作为无用文件删除。内容仓库仍由应用读取完整静态数据，未改动内容加载契约或数据格式。
