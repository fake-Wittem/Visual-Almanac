# 第一批风格档案建设

完成日期：2026-09-09。本记录描述档案内容与软件交付，不包含风格应用的实际项目验证记录。

## 建设结果

第一批新增 16 份档案，覆盖现代简约、自然有机、东方意境、未来科技四类，各 4 份。加上原有 12 份复古档案，当前内容库共有 **28 份、5 个分类**。

每份新档案包含一张独立海报、四种人工设定配色、设计特征、应用建议及三个有来源关联的发展阶段。本批共增加 **48 个设计史阶段、64 个色卡**。史实来源与当前视觉演绎分别说明，没有将生成场景当作历史影像或真实地点。

## 可复用的生产结构

- `src/content/styles/`：档案内容与引用来源；页面自动收集，新增档案不需要增加页面组件。
- `src/content/categories.ts` 与 `tags.ts`：登记四个新主分类及理性、未来感、水墨、通透、紫色标签；相关风格说明读取真实分类名称。
- `assets/poster-scenes/`：本批 16 张原创生成场景。保留源图，便于不重复生成地重新排版。
- `templates/posters/batch-one/`：每张海报的结构化配方，保留场景提示词、短标题、分色、四种颜色、边栏和三枚标签。
- `scripts/render-posters.ts`：固定 SVG 排版，按既有海报规范输出 1200 × 1500 PNG；与档案颜色不一致时拒绝输出。
- `public/images/originals/`：网站使用的最终完整海报；`npm run images` 生成浏览版本。

```bash
npm run poster:render
npm run check
```

场景为内置 imagegen 生成，外框、中文、HEX 和色卡由代码排版。普通构建不需要生成服务；重新排版需要系统中文字体。详细参数和输出行为见[海报生成规范](海报生成规范.md)。第一批配色标记为 `manual`，不把编辑配色误称为历史标准。
