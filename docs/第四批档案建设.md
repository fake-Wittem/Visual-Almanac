## 内容边界

每份档案包含四个手工设定的主题色、设计笔记、应用建议、相关档案，以及至少三个逐阶段引用的发展节点和至少两项参考来源。选题以已有清单为基础，优先增加媒介、空间和材料上的差异。

早期桌面与网页围绕屏幕、出版和信息组织，区别于 Y2K 的未来想象；日式日常简约聚焦现代生活尺度，区别于茶道和侘寂；热带现代关注遮阳、通风与现代结构，区别于热带殖民复古场景。古典园林以具体园林资料解释空间，拜占庭装饰保留历史及宗教语境。科幻界面讨论叙事性屏幕，生成艺术讨论规则与计算过程，街头模板喷绘讨论模板复制与公共图像，分别与真实操作规范、AI 图片及涂鸦字形区分。

## 图像与复现

中央场景由内置 imagegen 逐份生成，属于原创风格演绎，不是历史照片、馆藏复制或实际项目记录。完整提示词与排版参数保存在 `templates/posters/batch-four`，场景保存在 `assets/poster-scenes`，完整海报保存在 `public/images/originals`。

沿用 `scripts/render-posters.ts` 的 1200 × 1500 固定版式，确定性排版标题、边栏、四色色卡、HEX、标签和页脚。配色属于编辑设定，不代表各时代的统一标准色。

```powershell
npm run poster:render -- templates/posters/batch-four
npm run check
node scripts/verify-fourth-batch.mjs
```

验证脚本检查八类各一份及每类不超过四份、原图与场景无重复、资源尺寸、32 个色卡中心像素和 16 张浏览图片，并输出 `artifacts/batch-four/contact-sheet.png` 与 `verification.json`。内容校验检查引用关系，史实仍需对照来源正文判断。
