## 分类与计数规则

- 一个档案使用一个主分类，情绪、材质、颜色、媒介等交叉特征通过标签和相关档案表达。同一档案跨类推荐不重复计数。
- 八大类是本站的浏览分类，不是同一层级的学术流派谱系。表中区分历史流派、艺术运动、地域传统、社群文化、媒介专题与编辑主题；正式写作时继续核对术语。
- 已有档案保持文件 ID 和当前分类。表中“部分覆盖”不算新专题已收录；新建前必须证明内容边界独立，无法区分时合并或改用标签。
- “现代简约”不等于所有现代主义，“古典装饰”不等于严格古典主义，“东方意境”不代表全部亚洲文化。每份 REFERENCE 仍须准确说明时间、地点、来源与发展关系。
- `src/content/categories.ts` 已登记全部八类；古典装饰、先锋实验、街头流行随第二批各 4 份档案一同开放。
- 表内编号是维护清单编号，不是档案 ID。已收录名称链接至真实 JSON；待收录条目只有选题，不代表图片、史料或正文已经完成。

## 每次收录的维护流程

1. 从清单选题，检查既有档案和交叉表，明确主分类、名称、独立研究范围与拟用 ID。
2. 检索可靠资料；候选名称只是研究入口，不能直接作为史实。优先博物馆、档案馆、图书馆与学术机构，记录支持各阶段叙述的具体原文链接。
3. 按[内容维护说明](内容维护.md)制作数据，按[海报生成规范](海报生成规范.md)准备图片与配色。新分类首批落地时同步登记分类字典。
4. 每份 REFERENCE 必须包含概述、至少三个按时间排序的发展阶段、至少两项来源、逐阶段引用及当前视觉提炼。网络审美和编辑主题应交代所借鉴的历史脉络，不虚构正式流派的成立时间。
5. 填写设计特征与应用建议；不增加实际项目验证、实践记录或虚构案例。博物馆藏品、历史作品与展览可以作为设计史材料。
6. 通过现有内容校验并检查详情页的图片、配色、文字与来源链接后，将条目改为“已收录”，替换为真实 JSON 链接。候选发生更名时保留研究范围说明。
7. 同步更新本页日期、类别小计、总计、批次进度及 README 中的收录数量；从内容目录重新核对，不能以海报张数或相关推荐次数计数。

## 研究入口与依据边界

以下资料支持分类思路及部分历史方向，不表示 80 个待收录候选已经逐项完成史料核验。它们不能替代每份档案的具体引用，也不把本站八大类变成博物馆的官方分类。

- [V&A：What was Modernism?](https://www.vam.ac.uk/articles/what-was-modernism)：理解现代主义的思想与历史范围，为现代简约类区分历史与当代审美提供入口。
- [V&A：What is Postmodernism?](https://www.vam.ac.uk/articles/what-is-postmodernism)：理解后现代的复杂性、矛盾与戏谑；不把全部先锋实验等同后现代。
- [V&A：The Rococo style](https://www.vam.ac.uk/articles/the-rococo-style-an-introduction)：洛可可的工艺背景与形式，为流派专题和沙龙场景划分范围。
- [V&A：Art Nouveau — an international style](https://www.vam.ac.uk/articles/art-nouveau-an-international-style)：新艺术的跨地域发展及与工艺美术、现代主义的联系。
- [V&A：Arts and Crafts](https://www.vam.ac.uk/articles/arts-and-crafts-an-introduction)：工艺、材料与社会观念，为工艺美术独立建档提供入口。
- [Cooper Hewitt：Nature—Design Triennial](https://www.cooperhewitt.org/channel/nature/)：自然与设计的多种关系，为自然有机类扩充研究问题。
- [The Met：The Japanese Tea Ceremony](https://www.metmuseum.org/ko/essays/the-japanese-tea-ceremony)：茶事与器物的具体文化背景，避免把侘寂、茶室、现代简约混为一谈。
- [V&A：Punk to Pop](https://www.vam.ac.uk/exhibitions/punk-to-pop)：音乐与时尚的联系，为街头流行类的社群与媒介研究提供入口。

当前已收录档案的设计史原文来源见对应 JSON 的 `designHistory.sources`。后续候选仍需逐项补齐专门资料；前两批各档案均已附具体引用。
