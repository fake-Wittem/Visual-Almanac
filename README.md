# Visual Almanac · 视觉风格档案馆

收集审美，记录灵感。一个以图片、配色和设计笔记为核心的轻量网站，使用 Vue 3、TypeScript 和 Vite 构建，可独立部署。

包含 28 份风格档案：复古 12 份，现代简约、自然有机、东方意境、未来科技各 4 份。支持组合筛选、关键词搜索、配色/CSS 复制、原图查看与本机收藏。网站没有管理后台，内容通过代码维护。

## 本地运行

需要 Node.js 22.12+（建议 24）与 npm。

```bash
npm ci
npm run dev
```

访问命令输出的本地地址。图片浏览资源首次启动时自动生成。原图位于 `public/images/originals`，每份风格数据位于 `src/content/styles`。

```bash
npm run check    # 单元测试、内容校验、图片生成、类型检查、生产构建
npm run preview # 仅用于本地检查构建产物
```

## 内容与收藏说明

海报由用户提供，为 AI 生成参考图；设计笔记是基于图像的整理建议。每份档案的 REFERENCE 单独提供有引用来源的设计史时间线，区分历史事实与当前风格提炼；不收录实际项目验证记录。新增档案必须填写设计史并通过结构与引用校验，详见[内容维护](docs/内容维护.md)。英伦学院档案的四个 HEX 已核对海报标注，其他首批配色为海报色块的近似取样，页面明确标示。

收藏保存在当前浏览器的 localStorage，跨页面与刷新保留，不跨设备或浏览器同步。清除站点数据后收藏会消失。更新内容时保留稳定 ID，即可延续已有收藏。

本仓库未附加开源许可证；公开可查看不等于自动授予代码或素材再分发许可。
